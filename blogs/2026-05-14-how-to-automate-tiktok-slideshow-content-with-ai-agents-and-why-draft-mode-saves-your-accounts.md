This guide explains how to automate TikTok slideshow creation using AI agents and Postiz, chaining Hermes Agent skills for hook generation, image sourcing, Pinterest scraping, slide composition, and captioning via cron jobs on a $5 VPS. The key innovation is using "draft mode" publishing for new accounts to avoid algorithmic shadow bans that plague direct API publishing.
